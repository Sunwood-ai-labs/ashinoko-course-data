# Contributing / 変更の提案

Please include the course version/commit, affected files, source attribution, rights, intended precision and size changes. Report the verification commands you ran and distinguish unavailable browser checks. Never attach private source files, credentials, internal logs or unlicensed assets.

コースの変更はこのrepo、車体・操作・描画・ゲーム物理は[ゲームrepo](https://github.com/Sunwood-ai-labs/ashinoko-kurotora-drive)へ提案してください。データ変更後は内容をレビューしてchecksumsとrelease一覧を更新し、`npm test` を実行します。詳細は[更新手順](docs/MAINTENANCE.md)を参照してください。

Contribution does not automatically transfer copyright or add a blanket license.
