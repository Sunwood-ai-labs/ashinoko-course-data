# データの出典と精度

道路・湖岸・建物の基礎は © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)、標高・地形は[国土地理院](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)の情報に基づきます。沿道と植生の制作モデルはプロジェクト所有者から提供された資産をブラウザ向けに変換したものです。

平滑化されたルート・道路幅・沿道・植生・材質には制作上の近似と補完が含まれます。実道路の状況、交通規制、安全性、測量成果、特定作品の公式な正確性を保証しません。

[PROVENANCE.json](../PROVENANCE.json)には取得時点が確定できない項目をnullで残しています。未確認の日時・ライセンスを捏造せず、将来の更新で根拠を得られた項目だけ補完します。原Blenderファイルと原地図・DEMの完全な制作環境は含まれません。

元の制作時検査ではMeshopt圧縮前後の復号geometry buffer一致を確認していますが、現在のCIが元データから圧縮工程全体を再実行するわけではありません。このrepoのCIは公開スナップショットの構造・サイズ・チェックサムを検査します。
